# Tugas Machine Learning Sesi 2

## Deskripsi singkat
Repositori ini berisi hasil pengerjaan tugas sesi 2 program Machine Learning. Proyek ini mempraktikkan manipulasi data menggunakan bahasa pemrograman Python dan dataset titanic.

## Yang aku pelajarin
1. Memuat data menggunakan pustaka Pandas.
2. Melakukan proses Exploratory Data Analysis untuk mengenali struktur data.
3. Membersihkan data dengan menghapus kolom yang tidak relevan.
4. Mengisi nilai kosong pada kolom umur dan membuang baris kosong pada kolom pelabuhan.
5. Mengubah format teks pada kolom jenis kelamin dan pelabuhan menggunakan metode One Hot Encoding.
6. Menyeragamkan skala seluruh data menggunakan fungsi MinMaxScaler.

## Langkah Upload
1. Melakukan inisialisasi git dengan git init.
2. Menambahkan file ke area staging dengan git add .
3. Melakukan commit atau simpan perubahan dengan git commit -m "bebas".
4. Menghubungkan folder ke repository GitHub dengan git remote add origin https://github.com/makraev06/tugas-ml-sesi2
5. Terakhir mengunggah file ke GitHub dengan git push -u origin main.
